# 🐦 3D Boids Simulation with VPython

A beautiful, real-time 3D simulation of flocking behavior using **VPython**. This project visually demonstrates how birds (boids) behave collectively by following simple local rules like **alignment**, **cohesion**, and **separation** — resulting in natural, emergent movement.


---

## 🌟 Features

- 📦 Realistic 3D Boids simulation in a dynamic boundary box
- 🎨 Boids grouped by color with smoother bird-like motion
- 🧠 Natural flocking behavior: alignment, cohesion, and separation
- 🎥 Real-time camera controls and smooth trails
- 🕹️ Interactive buttons to:
  - Pause/Play
  - Speed Up / Slow Down
  - Spawn new colored groups randomly

---

## 📽️ Controls

| Action           | Key/Button   |
|------------------|--------------|
| Pause/Play       | UI Buttons   |
| Slow/Fast        | UI Buttons   |
